    사용자 가이드 (User Guide)¶

    Prism을 사용하여 A/B 테스트를 설계, 운영 및 분석하는 방법을 설명합니다.

    1. 실험 설계 (Design)¶

    성공적인 A/B 테스트를 위해서는 명확한 가설과 목표가 필요합니다.

    가설 설정¶

    • Bad: "버튼 색상을 바꾸면 좋을 것이다."
    • Good: "구매 버튼 색상을 파란색에서 빨간색으로 변경하면(Variant), 눈에 더 잘 띄어 구매 전환율(Metric)이 5% 상승할 것이다."

    실험 키 (Experiment Key)¶

    시스템에서 실험을 식별하는 고유 ID입니다. (예: buy_button_color, checkout_flow) - 코드와 Admin에서 동일하게 사용해야 합니다.

    2. 실험 운영 (Operation)¶

    Prism Admin을 통해 실험을 생성하고 상태를 관리합니다.

    상태(Status) 관리¶

    • DRAFT: 실험 생성 중. 트래픽이 할당되지 않음 (기본값 반환).
    • RUNNING: 실험 진행 중. 설정된 비율대로 트래픽 분배.
    • PAUSED: 일시 중지. 모든 트래픽이 기본값으로 돌아감.
    • STOPPED: 실험 종료. 승자(Winner)가 결정된 경우 특정 Variant로 고정 가능.

    트래픽 할당 (Allocation)¶

    각 Variant에 트래픽을 얼마나 보낼지 설정합니다. - Control (A): 50% - Treatment (B): 50%

    3. 분석 (Analytics)¶

    전환율 (Conversion Rate)¶

    전환 수 / 실험 참가 수 * 100

    신뢰도 (Confidence)¶

    현재 결과가 우연이 아닐 확률입니다. Prism은 P-value 등을 통해 통계적 유의성을 제공할 예정입니다.

    퍼널 분석 (Funnel Analysis)¶

    사용자가 목표 지점까지 도달하는 과정을 단계별로 분석합니다. 1. 상품 상세 조회 (100명) 2. 장바구니 담기 (40명, 40%) 3. 결제 완료 (10명, 10%)

    이탈률이 가장 높은 구간을 찾아 개선하는 것이 목표입니다.
