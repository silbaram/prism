실험 시뮬레이터

특정 User ID가 어떤 그룹(Variant)에 배정되는지 테스트할 수 있습니다.

문자열·숫자·불리언·null을 지원합니다. 속성 누락과 자료형 불일치는 실제 평가기와 동일하게 판정합니다.

배정 유지 사용 중: 저장된 최초 배정은 조회하지 않으므로 실제 유지 변형과 다를 수 있습니다.

미참여:

User user_12345님은 variant_a 그룹에 배정됩니다.

💡 사용 안내
  • 참여 비율, 실험 기간, 레이어와 전역 홀드아웃을 확인합니다. 저장된 최초 배정은 조회하지 않는 미리보기입니다.
  • 참여 사용자는 동일한 User ID와 변형 설정에서 같은 그룹에 배정됩니다.
  • User ID를 변경하면 다른 그룹에 배정될 수 있습니다.
  • 실제 코어 평가기로 사용자 속성과 타기팅 규칙을 확인합니다. 현재 상태 점검은 ACTIVE만 참여하며, 설계 미리보기는 상태만 제외하고 기간 등 나머지 조건을 적용합니다.
  • 시뮬레이션은 노출·전환을 기록하지 않습니다.
  • 각 Variant의 가중치(weight)에 따라 배정 확률이 결정됩니다.
