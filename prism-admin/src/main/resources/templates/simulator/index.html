💡 사용 안내
  • 참여 비율과 현재 시각에 따른 실험 기간을 확인하며, 미참여일 수도 있습니다.
  • 참여 사용자는 동일한 User ID와 변형 설정에서 같은 그룹에 배정됩니다.
  • User ID를 변경하면 다른 그룹에 배정될 수 있습니다.
  • 초안도 미리 확인할 수 있습니다. 실험 상태와 사용자 속성에 따른 타겟팅은 이 화면에서 평가하지 않습니다.
  • 시뮬레이션은 노출·전환을 기록하지 않습니다.
  • 각 Variant의 가중치(weight)에 따라 배정 확률이 결정됩니다.
