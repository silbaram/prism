이벤트 카탈로그

이 Prism 서버의 등록 이벤트, 실험 목표·가드레일, 유효한 노출에 귀속된 수집 이벤트를 함께 확인합니다. 이름의 대소문자와 앞뒤 공백을 구분합니다. 등록만으로 이벤트가 수집되거나 실험 설정이 바뀌지는 않습니다.

검색 결과 중 최대 100개를 표시합니다. 검색어를 구체적으로 입력하세요.

이벤트 이름설명등록 상태수집 상태발생 횟수수집된 실험 수최근 발생 (UTC)
일치하는 이벤트가 없습니다. 새 이벤트를 등록하거나 SDK로 이벤트를 수집하세요.

발생 횟수는 전체 실험의 유효한 이벤트 행 수입니다. 최근 발생 시각은 저장된 이벤트 시각이며 서버 수신 시각이 아닙니다. 전환율은 각 실험의 이벤트별 집계에서 확인하세요.
