    [0.2.0-alpha] - 2026-01-28 (Sprint 3)¶

    Added (추가)¶

    퍼널 분석 및 시각화 (prism-admin)¶

    • 퍼널 정의 관리 (CRUD)
      • 사용자 여정을 분석하기 위한 이벤트 단계(Steps) 정의 기능
      • 퍼널 이름, 설명, 순서가 있는 이벤트 목록 저장 (JSON 포맷)
      • Admin UI: /admin/funnels 메뉴 추가
    • 퍼널 시각화 리포트
      • Chart.js 기반의 수평 막대 차트로 단계별 이탈/전환율 시각화
      • Variant(실험군)별 퍼널 성과 비교 분석 기능
      • 날짜 범위 필터링 (최근 7일 ~ 90일)
    • 분석 알고리즘
      • 세션/사용자 단위의 순차적 이벤트 발생 체크 로직 (FunnelAnalysisService)
      • 이전 단계 대비 전환율 및 전체 여정 대비 전환율 계산

    인프라 및 기술 개선 (prism-infrastructure)¶

    • funnel_definitions 테이블 추가 및 JPA 엔티티 구현
    • JSON 저장을 위한 AttributeConverter 적용

    Technical Notes¶

    • 퍼널 단계는 유연성을 위해 JSON 타입으로 DB에 저장됩니다.
    • 분석 로직은 이벤트의 발생 순서(Timestamp)를 엄격히 준수합니다.

    0.1.0-alpha - 2026-01-18 (Sprint 2)¶

    Added (추가)¶

    E-commerce 퍼널 예제 (prism-examples)¶

    • 상품 상세 조회 API (GET /examples/shop/products/{id})
      • @PrismExperiment 어노테이션으로 buy_button_color 실험 자동 할당
      • PrismContext.getCurrentVariant()로 할당된 변형 조회
    • 장바구니 담기 API (POST /examples/shop/cart/add)
      • PrismConversionTracker.trackConversionSafe()로 ADD_TO_CART 전환 추적
    • 결제 API (POST /examples/shop/checkout)
      • PURCHASE 전환 이벤트 및 매출액(value) 추적
    • 주문 완료 API (POST /examples/shop/order/complete)
      • @PrismTrackConversion 어노테이션 기반 전환 추적 예제

    Spring Boot Starter 개선¶

    • PrismContext를 통한 현재 Variant 접근 편의성 증대
    • @PrismUserId, @PrismSessionId 파라미터 리졸버 안정화

    Core API¶

    • 퍼널 분석 API (GET /v1/analytics/funnel) - 단계별 전환율 분석
    • 사용자 여정 분석 API (GET /v1/analytics/journeys) - 경로 패턴 분석

    Technical Notes¶

    • 예제 모듈은 ConcurrentHashMap 기반 인메모리 저장소 사용
    • Controller 계층에서 Prism 통합 (Service 계층 순수성 유지)

    Known Issues¶

    • 예제는 인메모리 저장소 사용으로 서버 재시작 시 데이터 초기화
